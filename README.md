# CapCut Guide — capcutmodapk.github.io

Independent informational guide site about the CapCut video editor: features, templates, editing tutorials and honest safety information about modified APK files.

## What this site is

- 20 original guides (600–900 words each) on CapCut: what a mod APK is, premium vs free, safety risks, official install, templates, captions, keyframes, transitions, quality and export settings, TikTok and Reels editing, text effects, background removal, speed ramping, filters, audio editing, CapCut vs KineMaster, beginners and trending edits.
- 4 free in-browser tools: aspect ratio calculator, bitrate and export size calculator, caption timing helper, template idea generator.
- About, contact, privacy and disclaimer pages.

## What this site is NOT

This site does **not** provide, host or link to any modified APK file. The only download links point to the official CapCut app on Google Play and the App Store. It is not affiliated with ByteDance or CapCut.

## Tech

- Pure static HTML/CSS/vanilla JS, no build step, no backend.
- Deploy as a GitHub Pages organisation site (`capcutmodapk.github.io`).
